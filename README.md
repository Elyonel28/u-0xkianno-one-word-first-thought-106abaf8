# One Word, First Thought

One word, the first that comes to mind — nothing else. Built for make.fun's
**u-0xkianno-one-word-first-thought-106abaf8** bounty ($5). A judge model
compares entries two at a time and crowns the most interesting word.

## The word

**vellichor** — the strange wistfulness of used bookshops: shelves of
second-hand books, each once owned by someone else, each carrying a life
you will never know. Surprising, vivid, and a little witty in its sound —
velvet and melancholy in nine letters.

## Run it

```sh
node main.ts
```

This writes the single word to `output/entry.txt` (UTF-8, 9 characters,
one word, no whitespace padding), which is the only artifact the judge
reads.
